# FMCG Sales Analysis Dashboard

## Project Overview

This project analyzes FMCG (Fast-Moving Consumer Goods) sales data using Microsoft Excel. It presents an interactive dashboard to explore sales performance, revenue, profit, and distributor performance across different products and locations.

## Tools Used

* Microsoft Excel
* PivotTables and PivotCharts
* Slicers and interactive filters
* Data analysis and dashboard visualization

## Key Analysis Areas

* Distributor performance
* Category revenue and profit
* Province-wise revenue, sales, and profit
* Quarterly net sales
* Product-level sales and profit
* City-level sales, revenue, and profit

## Interactive Dashboard

The dashboard includes interactive filters for:

* Salesperson
* Product
* Year
* Distributor
* Province

These filters help users explore different segments of the dataset and compare business performance.

## Dataset

The workbook contains 2,000 records covering multiple cities, products, distributors, and sales periods from January 2025 to May 2026.

## Project Objective

The objective is to transform raw sales data into meaningful business insights and present the results through an interactive Excel dashboard.

## Files

* `FMCG_Dataset_DSA.xlsx` — Excel workbook containing the dataset, analysis sheets, and dashboard.

## Skills Demonstrated

* Data organization and validation
* Sales and profitability analysis
* PivotTable-based reporting
* Interactive dashboard creation
* Business data visualization
